# VALORIA PRODUCTION ART SYSTEM v1

## Canonical workflow
**Blender/Unity interactive authoring → visual review → reproducible source → CI certification.**

CI certifies reproducibility, hashes, Unity import, gameplay signature, zoom-9/mobile captures and regressions. CI is not the artistic authoring environment.

## Classification
### PRODUCTION ART SOURCE
Requires reproducible source, deliberate architectural modeling or controlled source reauthoring, real silhouette/depth at official camera, UV/material strategy, production GLB, zoom-9/mobile evidence, gameplay preservation and explicit visual PASS.

### GREYBOX / SUPPORT / TEMPORARY
Primitive boxes/cylinders/cones, minimal mathematical roofs, procedural layout geometry, hidden supports and unreviewed candidates are temporary by default. Blender does not automatically make them final art.

## Geometry standard
Hero Bastion is the upper richness anchor. Production secondary architecture should use layered plinths, recesses, jambs/lintels, cornices, buttresses, roof thickness/eaves, structural timber, asymmetry, selective wear and macro detail readable at zoom 9.

## Material standard
Canonical families: Eldoria Stone, Timber, Slate, Ground, Rock and Metal/Accent. Author at source level and preserve useful source PBR. Use basecolor, normal, roughness/smoothness, AO and variation masks where useful; edge wear, dirt, moss/humidity, trim sheets and decals are optional controlled layers.

## Final Look
Accepted development/final-look direction: ACES, restrained grade, warm key + cool fill, soft shadows, trilight ambient and restrained atmospheric fog. Renderer features must earn adoption by isolated A/B evidence.

## Camera
Orthographic remains canonical. Mild perspective failed the matched A/B.

## Density
Only after architecture/surfaces/final-look pass. Density must improve function, scale, life or world continuation and must not irreversibly occupy reserved parcels.

## Stop gate
Every promotion requires BEFORE/AFTER zoom 9 and mobile, gameplay signature preservation, and an explicit answer to: **closer to the reference, or merely a cleaner prototype?** If only cleaner, do not call it reference-quality final.

## External generation
Tripo is optional. If used later: multiview → HQ geometry → semantic segmentation/parts → Blender cleanup → modular source → PBR → Unity. Paid credits require owner authorization.
