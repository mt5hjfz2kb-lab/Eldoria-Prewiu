# Zona 1 — Producción visual aislada

Se ha creado una primera maqueta visual 2D procedural original con formas reconocibles de ciudades, bosques, canteras, campos, campamentos, ruinas, montañas y corrupción central. Tiene tres zooms y cámara desplazable, en el archivo de entrega `eldoria_zona1_visual.html` de la conversación.

**Importante:** es un ensayo visual navegable, no una escena Unity 3D ni arte aprobado. No se ha tocado el Bastión I ni el runtime canónico de Region 1. El navegador automatizado de este entorno devolvió `ERR_BLOCKED_BY_ADMINISTRATOR` al intentar abrir tanto archivo local como servidor local, por lo que no existe captura de navegador certificada. No inventar PASS.

Próxima integración artística: usar esta composición como pauta de ocupación, transformar cada familia en modelos o impostores reutilizables, integrar con `ZoneOneWorld` y verificar en Unity con capturas reales, cuando exista runner disponible sin conflicto con Bastión I.
