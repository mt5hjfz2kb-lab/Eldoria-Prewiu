# Visual reference index

This folder is the canonical index for approved visual targets referenced by `docs/VISUAL_BIBLE.md`.

## Current approved direction

### Valoria — Bastion I
Status: **approved direction / still iterating gameplay framing**

The approved target contains:
- Bastion as the dominant focal point;
- broken cyclopean arch as the signature ancient landmark;
- vertical cliff/terrace city structure;
- early reconstruction activity;
- cold ruined environment with warm inhabited pockets;
- distant, restrained violet Breach pressure;
- clear empty/ruined capacity for Bastion I→X growth.

The concept must be translated into a playable mobile 3/4 city view; it is not a literal screenshot contract.
