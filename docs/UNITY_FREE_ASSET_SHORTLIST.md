# Unity free asset shortlist — 2026-09-25

Purpose: zero-euro acquisition shortlist for the Valoria Art Benchmark and first representative Unity slice. This list is intentionally small. Every pack remains raw material and must pass the Eldoria Art Layer before production use.

## Download now — P0
1. FREE Slavic Medieval Environment Town Interior and exterior — EmacEArt
   - Role: houses, town architecture, props and supporting environment dressing for Valoria.
   - Why: free, URP-compatible, modular, recent release; useful breadth without forcing the visual identity.
   - Status: recommended for immediate import trial.

2. URP Tree Models — ALIyerEdon
   - Role: production-capable tree/vegetation candidates for Valoria outskirts and Frontier.
   - Why: free, explicit Unity 6 / URP compatibility, small package footprint.
   - Status: recommended for immediate import trial.

3. Free Fire VFX - URP — Vefects
   - Role: torches, braziers, hearths, Sawmill/Forge warmth and reconstruction feedback.
   - Why: free and explicitly compatible with Unity 6000 URP.
   - Status: recommended for immediate import trial.

4. Magic Effects FREE — Hovl Studio
   - Role: raw VFX components for Breach distortion, corruption pulses, impact/reward experimentation.
   - Why: free, URP-compatible; must be heavily art-directed and not used as a stock magic portal.
   - Status: recommended for sandbox-only import trial.

5. GanzSe FREE Modular Character - Fantasy Low Poly Pack — GanzSe
   - Role: temporary human-scale inhabitants/soldiers and silhouette/animation integration tests.
   - Why: free and built on Unity 6000.3.x with URP compatibility.
   - Status: recommended as production-prototyping material, not final Aldric/Lyra identity.

6. Human Basic Motions FREE — Kevin Iglesias
   - Role: idle/walk/run/basic movement coverage for temporary inhabitants and soldiers.
   - Why: free, widely used, useful to replace static cylinders immediately.
   - Status: recommended for animation plumbing.

## Keep / use selectively
- Free Pack - Modular Terrain — already imported; keep for cliffs/hills/blocking terrain.
- Simple Modular Castle Assets — already imported; keep only as structural/blockout fallback because its minimal low-poly language is below the target finish.
- European Forests - Realistic Trees — possible secondary vegetation source, but do not import until URP Tree Models is evaluated; avoid mixing incompatible vegetation styles.
- Medieval Fortification — potentially useful PBR masonry reference, but old Unity provenance makes it a test-only candidate rather than a first download.

## Do not buy yet
No paid castle, character, VFX, UI or environment pack until the Valoria Art Benchmark exposes a specific gap that the free stack cannot solve.

## Import order
Environment/town -> trees -> fire -> Breach VFX -> modular characters -> motions. Import one family at a time, evaluate in a sandbox scene, normalize scale/materials/palette, then promote approved prefabs to Eldoria production wrappers.

## Acceptance before production
URP renders without pink materials; licensing/source is recorded; scale is normalized; mobile camera remains readable; material count/texture footprint are acceptable; LOD/culling strategy exists where needed; the result visually belongs to Eldoria rather than reading as the original pack.
