# Reference-directed geographic reconstruction

Owner explicitly requested macro reconstruction and same-camera before/after, then replacement of old world node visuals. This candidate prioritizes the original03_vista_panoramica.png composition, not local material tweaks.

Independent editable layers live in RegionOneDirectedGeography:63-point coastal silhouette in FINAL world coordinates (roughly380wide,920long),9 connected river polylines,2 lakes,15 road polylines,36 authored grove groups and3 low ridges. No inverse X compression and no original-reference image projected into the scene. Geometry includes a new96k-triangle continuous coast/terrain grid and ocean continuation; source target transforms/colliders/save/gameplay untouched. Existing126 near trees retain source coordinates. Approximately15canopies/grove use the same previously retained faceted forest atlas. Old geography stays as reversible control, hidden in the candidate. The same new geographical layers apply at all zooms.

RGBA semantic texture encodes coastline distance, inland water, roads and grove ground; it is built once per Unity process. These are design masks, NOT the source reference and NOT a final screenshot. Real low coastal relief, narrow water and fine routes address the dominant silhouette/water-scale/forest-distribution gaps. Artist-painted landcover is subordinate, no procedural camouflage threshold. Peripheral haze is geography-based; middle land stays clear. Near world markers are still old in this macro-only trial: new node sprite atlas already generated separately, next integration after reviewing composition.

Native evidence contract: unchanged244 landscape/456portrait overview zoom and unchanged pitch/target. Each native run captures current geographic candidate and the exact old geometry/forest/ground control in the SAME actual camera, same scene, same gameplay progression, both panorama and regional orientations. Names *-antes-composicion*. Metadata records quaternion as well as position/zoom/target/aspect. Compare those numerically after download. Portrait should now cover most of designed region; fixed landscape camera crops north/south and must not be called a complete-region frame. No old-atlas-only A/B mislabeled as geography.

Existing gates remain, near shader expectation follows the intentional material replacement. Added checks: physical new terrain exists and every existing WorldHotspot remains dry and inside new coastline. Legacy static coast tests still validate the retained control.
