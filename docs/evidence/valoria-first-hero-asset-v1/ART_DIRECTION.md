# Valoria first hero gate — production decision

Canonical reference opened directly: `references/VALORIA_APPROVED_VISUAL_REFERENCE.jpg`.
Observed lower gate: compact square fortified towers, subdued aged grey limestone, continuous masonry, open portal with portcullis, blue/gold banners, warm entry lights. The upper citadel is not the lower gate's silhouette.

Base decision: reuse the repository and studio utilities, but author one compact square-tower gate mesh. V5 is visually rejected as the hero base: circular towers/conical roofs, a tall upper chamber, separated colour blocks. V8 squares the towers but retains huge isolated merlons and exaggerated projection. Both actual historical PNGs were opened. This task does not overwrite the concurrently running V5 calibration or main.

First candidate inspected in actual Blender hero/strategic renders. Retain the same architecture. Defects selected for correction: overly proud corner quoins, slab-like spandrel above the arch, sphere-like flames; strategic framing clipped the crown. Corrections: fitted spandrel masonry, tapered flame geometry, complete camera framing; adapt pinned BlenderMCP TCP/main-thread queue to reduce quoin depth and seat existing crenels. No extra towers or alternate gate variants.

Tool selection: Blender for architecture/UV/portable bitmap PBR and exports; recovered bridge for pinned source access; recovered BlenderMCP transport for a constrained surface/connection correction; recovered decision_policy for contradiction checks. Ollama localhost `/api/tags` failed with connection refused, executable and model runtime absent; do not claim Qwen ran. No paid services. Original Eldoria surface maps are used rather than another complete brick-pattern image over actual brick meshes; that avoids double-scaled masonry joints. No third-party texture licence claim.

Acceptance separates artistic judgement, GLB import checks, Unity integration, and physical mobile performance. A green source workflow is not a visual PASS. No Unity runner is claimed while the live registry reserves it for `valoria-mesh-only-worldspace-proof-20261010`.
