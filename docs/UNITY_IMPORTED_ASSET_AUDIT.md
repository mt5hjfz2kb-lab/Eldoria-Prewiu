# Imported assets — Valoria benchmark trial (2026-09-25)

Scope: Unity 6000.3.23f1, URP. This is a source inspection and a five-prefab integration trial. Editor import, EditMode, PlayMode and the Windows build passed in [Actions run 36181313966](https://github.com/mt5hjfz2kb-lab/Eldoria-Prewiu/actions/runs/36181313966) at `774d0dc819adabf9917cbe7981b92093cbf4022c`. Rendered appearance and player performance still require visual/device review.

| Pack in repository | Source findings | Decision |
| --- | --- | --- |
| `EmaceArt/Slavic World Free` | 238 prefabs, 213 FBX, 16 materials. Ten materials reference the URP Lit shader GUID; others include built-in/legacy grass and water. Its included URP instructions describe a 2019 Standard-render origin and separate URP support. | Trial: shed, house and one tree in Valoria. No water/grass/wind shaders or full example scene yet. |
| `Mega Fantasy Props Pack` | 284 prefabs, 280 FBX, 59 materials; 57 use the built-in Standard shader (`fileID: 46`). Unadapted meshes are likely pink under URP. | Trial: ruined tower and firewood. The Eldoria presentation bridge maps instance materials to URP Lit and carries across base textures; original pack files stay intact. |
| `NatureStarterKit2` | 13 prefabs and 52 legacy C# scripts, including Standard Assets image effects and editor inspectors; material/shader set is mixed. This is a separate older nature pack from the shortlisted URP Tree Models. Unity 6 rejected two uses of the removed `AutomaticTruecolor` enum; the inspector now uses `TextureImporterCompression.Uncompressed`, and the next Editor import compiled. | Quarantine from the production scene. Its compile issue is resolved, but the custom shaders, URP appearance and mobile cost are not approved. |

Trial selections: EmaceArt `EA03_Village_OutBuilding_Shed_01a_PRE`, `EA03_Town_House_Comp_01a_PRE`, `EA03_Nature_Tree_03c_PRE`; Mega `tower_destroyed`, `firewood`. References live in `Assets/Eldoria/Resources/Valoria/ExternalAssetLibrary.asset`. `ValoriaKit.BenchmarkPiece` instantiates them as visuals, fits their bounds to a specified footprint, disables their source colliders/scripts, and converts legacy instance materials. The existing sawmill and barracks `WorldHotspot` collider volumes remain in place; procedural visuals are retained as fallback if a reference fails. No Domain, Application, economy or progression code changes.

These are **trial assets**, not an approved art baseline. The granary, Bastion keep, road, terrain transition, human silhouettes, fire and Breach remain to be addressed in the benchmark. A human visual comparison at target mobile resolution must judge scale, silhouette, color and readability before broader reuse. Unity PlayMode checked that selected prefab references resolve, instantiated renderers exist, legacy materials convert to supported URP shaders and the sawmill hotspot collider remains enabled. It did not inspect screenshots or play the full route in the new player.

Source/license provenance: all three packages were imported by the owner from the Unity Asset Store into this repository. Their bundled files do not provide a complete license receipt or package/version identifier. Record their exact Asset Store listing and Unity Asset Store EULA terms from the owner's package inventory before declaring any asset production-approved; no purchase is authorized. Current integration is an internal zero-cost trial.
