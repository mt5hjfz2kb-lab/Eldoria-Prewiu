# M04 V1 isolated deterministic incidents
`tools/m04/incidents.mjs` receives **structured** findings and classifies their declared domain. Origin `probe` cannot be falsely assigned to game. For visual-specific diagnostics, preserve the existing `tools/classify-visual-failure.mjs` upstream; this is a general result normalizer, **not** a replacement for visual diagnosis. Fingerprints omit run/sha/time to deduplicate across occurrences; run, sha, artifact, scenario and evidence are retained in observations.
`ingest(registry,finding,ownership)` is a pure function: caller is responsible for persistent storage, compare-and-swap and authentication. It never posts GitHub issues or invokes jobs. `transition` requires specific independent verified certification claim and same scenario/gate/candidate to close; however the caller-supplied certificate `verified:true` must be established using the trusted M03-B/C provider pipeline before production usage. This V1 does **not** prove that external authority on its own.
`forM16` is a read-only summary, not a dispatch. `executiveReport` outputs counts; no automatic DG issue write.
Historical persistence is represented by immutable functional snapshots and explicit transition events, but without an authorized multiwriter durable CAS backing store. Do not claim official incident service/end-to-end automation.
Reproduce isolated tests: `node --test tests/m04/incidents.test.mjs`.
