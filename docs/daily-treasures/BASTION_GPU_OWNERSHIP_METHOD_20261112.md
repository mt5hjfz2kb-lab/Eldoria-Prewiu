The original9material beta issue is a different isolated project; do not conflate it with this GPU failure.

After two failed city attempts, the capture method changes rather than weakening the authentic-image assertion. A checked single-sample/depth working target receives a documented URP StandardRequest on a detached Base Camera. Real GPU pixels are then copied to a separately allocated, checked, non-MSAA/depthless persistent RenderTexture that is NEVER attached to a camera. The camera is detached before cleanup; the working GPU storage, temporary light and camera are released immediately. The panel alone owns the returned snapshot and releases it on close/rotation/teardown. There is no ReadPixels, cloned Texture2D, invented castle, synthetic replacement image, scene/save write or altered gameplay camera. Original active built-tier resolution, bounds/framing and real scene materials remain intact. Device memory/visual improvement is not asserted without measurement.

Each allocation and post-render/post-copy hardware state is now checked. If the working render or copied target is lost, the code reports the precise stage and preserves the truthful visible city fallback; it must not recreate an empty texture and call it a rendered Bastion. Existing Editor checks still require actual live GPU storage, nonblank/nonflat masonry pixels, genuine built-model silhouette and correct orientation recapture. Source20-file Roslyn check PASS; this is not Unity API/render or artistic acceptance. The underlying reason the previous target lost storage is not conclusively known, so the new ownership method is a testable hypothesis pending the next legitimate native turn.

Official APIs: https://docs.unity3d.com/cn/6000.0/ScriptReference/RenderTexture.Create.html and https://docs.unity3d.com/ja/current/ScriptReference/Rendering.RenderPipeline.StandardRequest.html . The latter renders a full URP Base Camera stack; the temporary Base Camera has no overlay stack. No same-turn retry while Resources/Interface/Beta wait, no ART_APPROVED or merge/publication.
