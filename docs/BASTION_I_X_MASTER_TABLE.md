# Eldoria — Bastion I–X master table

Status: canonical design audit / 2026-09-28

Purpose: preserve the validated web vertical-slice chronology while identifying only the places that genuinely need polish or further design. **Validated decisions remain binding unless a later explicit decision supersedes them.** Unity adapts presentation/implementation; it does not silently redesign this progression.

## Reading the table
- **CLOSED** = core role/chronology is decided; implementation/art may still be incomplete in Unity.
- **POLISH** = decision exists but pacing, presentation, visual growth or teaching needs refinement.
- **OPEN** = a meaningful design identity or exact rule is still genuinely unresolved.
- Every Bastion ascent should communicate: **message → visible Valoria change → new action/capability**.

## Relicario teaching cadence
The first contact at VII should **not** dump all mechanics at once. Recommended canonical teaching order:

1. **VII first contact:** receive/reveal first card; explain that Reliquias live in Relicario; basic effect; use now vs conserve.
2. **VII later / VIII:** rarity language and the fact that some Reliquias have unusual properties; introduce **Indestructible as a property, not a rarity**, only when relevant.
3. **VIII–IX:** N/S/E/O becomes meaningful; introduce Practice through an actual need/action rather than a rules lecture.
4. **IX–X or post-X:** reinforce combinations/advanced collection behavior; future Duel remains visibly future/locked until real PvP exists.
5. **Post-X:** deeper collection/duel strategy can expand without burdening the prologue.

Current acquisition rules remain: ordinary eligible world-enemy victories have extremely low Common/Rare chances; hunting = 0%; Epic/Legendary are not ordinary drops and need special sources.

## Bastion ascent message contract
Each ascent gets a compact celebratory/meaningful message, not merely a level number. Final copy can change, but the functional pattern is fixed:

| Level | Message intent | New action emphasis |
|---|---|---|
| II | **Valoria can defend itself.** | Recruit troops / March. |
| III | **The frontier is opening.** | Food, hunting, Fissure/Lyra. |
| IV | **You choose how Valoria recovers.** | First autonomy/priority choice. |
| V | **Stone returns to Valoria.** | Produce/use stone. |
| VI | **Valoria can forge power from what the Breach leaves behind.** | Forge/equip. |
| VII | **Recovery becomes understanding.** | Códice + first Relicario decision. |
| VIII | **Valoria is no longer alone.** | Wider-world consequence / Maelis. |
| IX | **No one will tell you how to prepare.** | Independent two-hero/multi-system mastery. |
| X | **You are ready to lead beyond the ashes.** | Finale, Hospital recovery, graduation. |

These are **intent lines**, not final localized copy.

## Cross-level visual progression rule
Unity must make progression visible. The city should not remain the same scene with extra buttons. Preserve the certified kernel/Master Envelope and express growth through reversible/controlled layers such as:
- building architecture/tier changes;
- repairs and removal/containment of ruin cues;
- roads, retaining masonry and circulation refinement;
- occupied plots and district activation;
- population, carts, stockpiles, smoke, banners, workshops and military/civic props;
- Bastion silhouette/roof hierarchy evolution;
- increased inhabited density without blocking hotspots or the 12-step route.

Major visual eras can carry the biggest transformations, but **every Bastion level should provide at least one perceivable growth cue**.

## Genuine remaining design work
1. **Bastion IV identity** — define the exact autonomy challenge and its visible Valoria consequence without adding a gratuitous system.
2. **Bastion V stone tuning** — decide which upgrades begin requiring stone and in what ratios; the Cantera’s fundamental role is already closed.
3. **Bastion VII teaching cadence** — implement the staged Relicario onboarding above and avoid menu-dump presentation.
4. **Bastion X finale feel** — tune ceremony/pacing so it is unmistakably tutorial graduation while preserving desire to continue.
5. **XI+ progression** — design the post-prologue structure separately; do not simply repeat tutorial beats. Long-range city planning currently protects roughly Bastion 25–35 headroom, but exact content/cap remains provisional.
