## Reference gap and stop rule

The approved benchmark in `docs/ELDORIA_VISUAL_BENCHMARK.md` has multiple inhabited tiers, carved rock terraces, monumental arches, connected masonry, a readable central civic space, water/valley depth and consistent texel/material scale. This proof retains a strong Hero Bastion but leaves the lower district sparse; the terrain is a simple mound; the photograph is visibly a different level of naturalism. Neither full-frame run crosses a visual category. Stop moving, scaling or adding individual prefabs on this substrate.

The tested library resolves individual buildings, stairs, stone fragments and rocks. It does not currently provide one authored **Hero-to-city transition** that joins the Bastion's irregular rock skirt to a civic terrace, retaining walls and the three functional plots as a coherent environment module. Procedural Unity mesh, Blender grid, native extrusions and sampled modules all failed full-frame review. This is a concrete geometry/art-direction gap, not a Unity compile, PBR or renderer failure.

## Decision

**C for the current environment authoring strategy.** Unity/URP remains capable, and gameplay did not regress, but the current asset assembly cannot be promoted toward the approved image. The next candidate must be authored against the exact full-frame silhouette and judged against the reference. A single contiguous terrain/terrace/retaining-wall connector is the candidate geometry gap. Before any Tripo credit, create an exact operational reference for that piece, show it with its expected cost, and obtain fresh approval. No Tripo request has been sent.
