# VALORIA NATION 1 — AUTHORED PRODUCTION BUILD v1

## Production decision

This is a full player-facing production pass, not another isolated asset proof.

Route: **environment_composition -> Unity first**, as required by Toolchain Automation v2. No Tripo or paid generation is needed for the first build because Eldoria already owns rich Hero, Aserradero, Cuartel, Granero, MidTier Architecture, Terrain/Terrace, rescued transition and Stone wall/gate/tower families.

Accepted starting visual: `7a564bc5056bb7166b7704c313ae4db7d55d4530`.

## External production research -> applied choices

Environment-art guidance supports a strong top-down directional axis, modular reuse with consistent materials, monumental stairs for hierarchy, and authoring primarily for the actual player camera.

Applied:
1. Hero becomes a complete civic/defensive core rather than an isolated model repair.
2. Existing high-detail terrace/rock/stair modules form a layered base around the accepted Hero.
3. One monumental stair connects plaza -> Hero.
4. Existing wall/tower language frames the rise.
5. MidTier architecture fills civic seams without replacing Aserradero/Cuartel/Granero.
6. Urban props add readable density in functional yards.
7. Validate zoom 9 and mobile first.

No extra tool is introduced because a geometry gap is not yet proven.
