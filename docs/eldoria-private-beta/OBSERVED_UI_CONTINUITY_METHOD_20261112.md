# Preserve a genuine foreground QA browser instead of replaying startup after every observation

Several strict whole-script checks stopped on newly observed interface details (queued typewriter controls, contextual training choice, diagnostic badge covering a heading). These did not reset the real engine, but closing the test browser after an assertion made the method inefficient. The next method keeps one genuine Mac WebKit context alive and exposes original-frame artifacts between observed UI actions.

This is one foreground90-minute test, not a recurring automation, supervision or new workstream. It creates no chat, PR, product change, deployment or tester invitation. The canonical Windows PR179 source remains frozen. Only this isolated QA execution ref holds command data. Commands require the active run ID, next sequence and last original screenshot SHA. Every action re-reads original pixels via Apple Vision. Text clicks must match a unique currently visible label; point clicks additionally require two fresh visible guards and explicit provenance/reason. Only bounded waits, observed clicks, quantity digits, safe editing keys and finish are implemented. No arbitrary JS, native command, save mutation or clock API is exposed.

Every result publishes an immutable original PNG, OCR and state/event record through the official GitHub artifact client. Invalid/stale actions publish a new frame and retain the browser. Finish, timeout and failures attempt the already-proven official earned IndexedDB snapshot after closing only this QA game and its regenerable asset cache; an assertion must not throw away earned troops. No owner save or cookies are accessed.

Input is the immutable actual checkpoint from the completed twenty-archer run if successful, otherwise the previously SQL-verified actual BastionII barracks checkpoint. No state is fabricated. New state and campaign outcomes still require actual event/save verification; neither protocol success nor a screenshot certifies physical iPhone, art or a release. Official actions/toolkit artifact interface and the published @actions/artifact2.3.2 package were checked before use.

Local alternate testing was investigated: Chromium is installed but this runtime refuses its IPC socket (Operation not permitted). Do not repeat browser flag changes or bypass that restriction. Use the independent Mac test while Windows performs the real native build.
