## Required inputs for a new representative family
A family may enter this recipe only with:
- one approved editable real mesh source;
- one semantic interaction identifier;
- canonical viewport / world anchor;
- canonical visual-reference crop or projector authority;
- explicit material fallback;
- no unresolved silhouette/identity failure.

If no acceptable real mesh exists, stop and classify the blocker before reopening any source-authoring dependency.

## Standard production sequence
1. Stage approved real geometry.
2. Load locked SHARP 600K visual layer.
3. Restore canonical bounded camera.
4. Instantiate invisible semantic interaction substrate.
5. Import and align real editable mesh to semantic anchor.
6. Verify bounds + screen-space alignment.
7. Verify interaction at HOME and bounded pan/zoom.
8. Capture original real-geometry material evidence.
9. Apply target-conditioned appearance to real mesh.
10. Evaluate HOME against canonical region.
11. Evaluate pan-left / pan-right for silhouette/parallax stability.
12. Enforce full-frame takeover guard.
13. If projection fails structurally, switch to the already-authorized authored/PBR fallback; do not micro-tune projection indefinitely.
14. Capture final integrated evidence.
15. Promote only after visual review, not green CI alone.

## Failure classification
- **GEOMETRY / IDENTITY FAIL**: stop appearance work; source mesh must be corrected/replaced using an already-authorized route.
- **ALIGNMENT FAIL**: fix transforms/anchor only; do not regenerate art.
- **INTERACTION FAIL**: fix semantic substrate / collider mapping only.
- **APPEARANCE STRETCH / DUPLICATION / SIDE COLLAPSE**: stop projection tuning and use authored/PBR fallback.
- **GAUSSIAN RUNTIME FAIL**: retain real mesh/gameplay substrate and follow the existing visual fallback system; do not reopen random generator R&D.
- **RUNNER / OBSERVABILITY FAIL**: classify infrastructure separately from visual failure.
- **VISUAL FAIL WITH TECH PASS**: do not promote.
