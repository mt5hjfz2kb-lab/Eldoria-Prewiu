## Scope
One subject only: **Lower Gate** from the canonical reference.

## Root-cause premise
Prior evidence shows that Unity integration, camera matching, gameplay preservation, PBR plumbing and automation are not the dominant blocker. The repeated ceiling is source-art quality: screen-visible primary forms and authored identity remain below the premium target. Therefore this block evaluates source creation before downstream rescue.

## Exact-input requirement
Before any vendor call, create a consistent isolated Lower Gate multiview package:
- front
- left
- back
- right
- same identity/proportions/details across views
- no UI, labels, arrows, frames or contact-sheet layout
- exact bytes persisted in the repository

The owner must see the exact inputs and current vendor cost before approving paid execution.

## Gate
Neutral evaluation before Unity and before candidate-specific rescue:
- geometry / silhouette >= **4/5**
- architectural identity >= **4/5**
- official-camera readability >= **4/5**
- no catastrophic visible topology defect

A candidate below 4/5 is not repaired into compliance by bespoke Blender sculpting, shaders, decals, terrain or Unity presentation. Reject it as a source method.
