This is therefore a high-density raw generation, not an optimized production module. ## Isolated Unity gate

`TripoModuleReview.Capture` is isolated under `Unity/Assets/Eldoria/ArtTests/ImageTo3D/`. It imports only the module, normalizes it for review, creates a neutral terrain plane and a short review road, adds a MeshCollider to each imported MeshFilter, checks positive/negative Physics.Raycast, and captures 1280×720 at orthographic **19 / 12 / 9** plus one oblique view. The terrain/road primitives are test context only and never replace the supplied architecture.

The workflow stages the exact SHA from the Windows runner Downloads when available under either `Eldoria_Module_TowerWallRock_H25.glb` or `Eldoria_Model_Tower.glb`. If absent, the review is skipped rather than fabricating Unity evidence. `Valoria.unity`, `VisualWorld` and gameplay are not touched.

## Comparison with full-Bastion route

The previous full-Bastion end-to-end trial proved import/raycast but failed the art gate: one fused mesh, degraded architectural legibility at 19/12/9 and broken useful texture import. The small-module strategy is structurally better because generation is focused on one reusable architectural idea and can preserve shape more coherently, but **this raw file is not yet a kit module**: it is still one fused mesh, has no UVs/textures, and carries ~501k triangles.

## Required external optimized version

Produce this version outside Work; do not use aggressive Tripo retopo as the authoritative target:

- **Triangles:** target **20k–35k** for the complete tower+wall+rock module; hard review ceiling **50k**. Preserve silhouette/openings/roofline/rock transition before chasing the lower number.
- **Vertices:** expect roughly <= 25k–40k depending on seams; triangle count is the primary gate.
- **Meshes:** **3–5 semantic meshes**: Tower, Wall, RockBase, optional RoadJoin/Trim. Do not return one fused object.
- **UV:** one valid non-overlapping UV0 set per mesh for baked PBR; lightmap UV only if later required.
- **Textures:** **2K maximum per material set** for the review source; prefer one shared 2K atlas/set across Tower+Wall and one 1K–2K rock set. BaseColor + Normal + packed Metallic/Roughness/AO (or an explicitly documented URP-compatible equivalent).
- **Materials:** target **2 materials**, hard ceiling **3** for this module.
- **Format:** **GLB 2.0**, Y-up, transforms applied, base at ground, sane pivots for snapping/reuse; no Draco requirement for the authoring source.
- **Collider:** simplified box/convex/low-poly colliders should be authored separately for production; the review MeshCollider is only a gate.
- **LOD:** not required for the first re-entry GLB, but LOD0 topology must be clean enough to derive LOD1/LOD2 without rebuilding the asset.

## Re-entry checklist for every future module

1. Record source SHA, generator/export settings and rights.
2. Measure meshes, vertices, triangles, materials, UV0, normals, texture count/resolution before Unity.
3. Confirm semantic part separation and useful pivots.
4. Import only into `ArtTests/ImageTo3D/`.
5. Capture 19 / 12 / 9 + oblique with fixed framing.
6. Verify collider/raycast hit plus empty-space miss.
7. Inspect rock/terrain/road junction from front and oblique.
8. Record any manual cleanup minutes and whether the operation is repeatable.
9. Reject if silhouette/architecture fails, if semantic separation requires near-rebuild, or if material/UV work is effectively starting from zero.
10. Promote to kit only after the optimized version passes visual, interaction and cost gates.

## Verdict

**B — viable with external optimization.** Small-module generation remains the more promising direction than the full-Bastion generation, but this exact raw GLB is not production-ready. Its geometry can be used as the high-detail source for external retopo/bake/semantic separation; the next acceptance gate is the optimized 20k–35k / 2-material / 3–5-mesh GLB in the same isolated scene.
